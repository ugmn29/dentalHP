# 広告・HP計測設計メモ

作成日: 2026-06-27

## 何が分かるか

HPのファイルだけでは、過去にどこで離脱したかは分からない。

ただし、現在のサイトにはGA4とMicrosoft Clarityが入っているため、今後の広告流入については以下を確認できる。

- どのページに流入したか
- どのページで次に進まず離脱したか
- どのCTAがクリックされたか
- WEB予約クリックが発生したページ
- 電話タップが発生したページ
- Clarity録画・ヒートマップ上で、どこまで読まれたか

## 追加したGA4イベント

| イベント名 | 発火条件 | 用途 |
|---|---|---|
| web_reservation_click | HubDentのWEB予約リンクをクリック | Google広告の主要CV候補 |
| phone_click | 電話リンクをタップ | Google広告の主要CV候補 |
| page_view | クライアント側ページ遷移 | SPA遷移時のページ閲覧補完 |

## イベントに含める情報

| パラメータ | 内容 |
|---|---|
| contact_method | web_reservation または phone |
| link_url | クリックされたURL |
| cta_text | ボタンやリンクの表示テキスト |
| cta_location | header / footer / section などの位置 |
| page_path | クリック時のページURL |

## Google広告側でやること

GA4とGoogle広告を連携し、以下のGA4イベントをGoogle広告のコンバージョンとしてインポートする。

```text
web_reservation_click
phone_click
```

最初は両方をPrimaryにしてよい。実予約数との差が大きい場合は、WEB予約完了ページや予約システム側の完了イベントをPrimaryに切り替える。

## Clarityで見ること

Clarity側では以下を見る。

- PMAX流入ユーザーの録画
- トップページのファーストビューで迷っていないか
- WEB予約ボタンまでスクロールされているか
- スマホ下部固定CTAが押されているか
- 小児ページ・こども矯正ページでどこまで読まれているか

## 離脱判断の見方

| 状況 | 解釈 | 改善案 |
|---|---|---|
| トップで直帰が多い | 検索意図とファーストビューがずれている | 「豊洲駅徒歩2分」「土日診療」「WEB予約」を上に強く出す |
| 診療ページ閲覧は多いが予約が少ない | 内容理解で止まっている | 料金・期間・よくある質問・CTA位置を改善 |
| 料金ページ後に離脱 | 費用不安が残っている | 相談導線、分割/支払い、費用の内訳説明を追加 |
| 電話クリックが多くWEB予約が少ない | 急ぎ・不安が強い | 電話受付時間や当日相談の説明を強化 |
| WEB予約クリックは多いが実予約が少ない | 予約システム側で離脱 | HubDent側の画面・入力項目・空き枠を確認 |

## 週次レポートで見る数字

| 指標 | 参照元 |
|---|---|
| 表示回数・クリック数・広告費 | Google広告 |
| WEB予約クリック数 | GA4 / Google広告CV |
| 電話タップ数 | GA4 / Google広告CV |
| 予約クリック単価 | Google広告 |
| ページ別流入数 | GA4 |
| ページ別離脱・エンゲージメント | GA4 |
| ヒートマップ・録画 | Clarity |
| 実予約数 | HubDent / 院内集計 |

## 注意点

WEB予約クリックは「予約完了」ではない。最初の学習用CVとして使い、実予約数との差を毎週見る。

最終的には、予約システム側で予約完了イベントを取れる状態にするのが理想。
